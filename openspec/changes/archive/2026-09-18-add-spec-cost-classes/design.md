# Design: Add Spec Cost Classes

## Declare once, at the spec

A class is a property of the work, and the work is named by its spec. Declaring it per commit or per
session asks for the same fact hundreds of times and gets it never. One line per spec, committed and
validated against the vocabulary, is inherited by every record that cites the spec, and the resolution
order keeps a more specific declaration (session, then trailer) ahead of it. Nothing is defaulted: a spec
with no line stays `unclassified`, and the panel says how many records resolved each way.

## The R&D figure is dollars and hours

Planning and tax credits count both. The panel gains the allocated share and the operator hours per class
beside the reported cost, each in its own column, never summed.
